## 2. Approach A: Differentiable Physics & PINN

### 2.1. The Physics Engine (Julia + Zygote)

We built a custom Finite Element Analysis (FEA) solver in Julia using Zygote.jl for Automatic Differentiation (AD).

**Mechanism:** Uses a "Soft Screw" Gaussian projection to map discrete coordinates to a continuous stiffness field.

**Constraint Handling:** Implemented enforce_lbracket_bounds to strictly confine screws to the L-Bracket geometry, handling the re-entrant corner void.

**Stability:** Solved numerical singularity issues (NaNs) using matrix damping ($10^{-6}I$) and gradient clipping.

### 2.2. Data Generation

A dataset was generated by running the Julia optimizer on random initializations.

**Samples:** 39 valid optimization trajectories.

**Distribution:** Compliance values range from 524 J (Stiff) to 1336 J (Flexible).

**Visual Validation:** Screw placements conform to the L-Bracket geometry (see dataset_visualization.png).

### 2.3. Neural Network Surrogate (PINN)

A Multi-Layer Perceptron (MLP) was trained on the generated data.

**Architecture:** 4 Inputs (x1, y1, x2, y2) -> [64, 64] Hidden Layers -> 1 Output (Compliance).

**Accuracy:** <0.2% Mean Absolute Error against Ground Truth FEA.

#### Performance:

**Julia Solver Time:** ~10.36 ms per iteration.

**PINN Inference Time:** ~0.047 ms per iteration.

**Acceleration Factor:** ≈222x.

## 3. Approach B: Moving Morphable Components (MMC)

The MMC framework has been successfully ported to Python/SciPy.

**Prototype:** MMC_LBracket.py successfully simulates moving components on an L-shaped domain.

**Result:** Discrete circular components (fasteners) successfully migrated from initialization points to the high-strain inner corner over 15 iterations.
